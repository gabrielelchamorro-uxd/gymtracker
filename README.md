# GymTracker

Aplicativo de acompanhamento de treinos com sincronização em tempo real via Supabase.

## Acessos

### Aluna
https://gabrielelchamorro-uxd.github.io/gymtracker/gymtracker-aluna.html

### Treinador
https://gabrielelchamorro-uxd.github.io/gymtracker/gymtracker-treinador.html

## Funcionalidades

- Treinos A, B, C e D
- Registro de cargas e séries
- Histórico de treinos
- Sincronização em tempo real
- Painel exclusivo do treinador para editar treinos

## Tecnologias

- HTML, CSS e JavaScript
- Supabase (Banco de dados + API)
- GitHub Pages (Hospedagem)
